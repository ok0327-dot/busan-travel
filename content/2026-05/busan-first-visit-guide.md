부산 처음 오시는 분들한테 가장 많이 듣는 질문 5가지 + 진짜 답변 정리했어요.

**1. 며칠이 적당해? — 2박 3일 정답**

1박 2일은 너무 빠듯해요. 핵심 명소 (해운대 / 광안리 / 남포동 / 감천 / 영도) 다 도려면 최소 2박 3일. 더 길게는 부산 외곽 (기장 / 송정 / 다대포) 추가해서 3박 4일도 좋아요. 저는 친구들 올 때 무조건 2박 3일 권해요.

**2. 어디 호텔? — 해운대 vs 서면 vs 남포동**

해변 분위기 + 야경 = 해운대. 마린시티 라인 호텔이 가성비 좋고 야경 끝내줘요.
쇼핑 + 맛집 + 교통 허브 = 서면. 부산진구 한가운데, 어디든 30분 안에 도착.
원도심 + 시장 = 남포동. 자갈치 + 광복로 + 영도까지 도보 가능.

저는 해운대 추천. 부산 첫 방문은 바다 보면서 자는 게 정답이거든요.

**3. 교통은 어떻게? — T-money + 지하철 답**

T-money 카드 편의점에서 5천원에 사세요. 지하철 + 시내버스 + 마을버스 다 됨. 환승할인 기본 600원 차감.

택시는 단거리 (5km 이하) 제외하고는 비추. 부산은 지하철 노선이 잘 짜여 있어서 90% 코스 지하철로 해결돼요.

부산김해경전철 (BGL) 는 김해공항 출국 전에 한 번 타볼 만. 김해공항 → 사상역 → 지하철 2호선 환승해서 시내 진입 30분.

**4. 결제 — 카드 vs 현금?**

대부분 카드 OK. 시장 (자갈치/국제시장) 만 현금 챙기세요. ATM 어디나 있어요.

외국인 분들은 트래블월렛 / 트레블로그 카드 미리 발급 받아오면 환전 수수료 절약. KRW 충전해서 그대로 결제.

**5. 진짜 꼭 먹어야 하는 것?**

돼지국밥 — 무조건. 서면 / 동래 / 부산진구 어디든 100m 안에 한 곳은 있음.
밀면 — 부산만의 차가운 면 요리. 여름에 특히.
자갈치 회 한 접시 — 시장 안 회 가게에서 직접 골라 먹는 그 경험.
완당 (어묵) — 현장에서 먹는 게 진짜.
비빔당면 — 남포동 길거리 음식 중 부산 시그니처.

이 5가지 다 도전하면 부산 음식 80% 본 거예요.

마지막 팁: 부산 사람들은 '서울 사람 같아 보이게' 행동하면 친절하게 안내해줘요. 부산 사투리 들렸을 때 당황하지 말고 그냥 표준어로 답하세요. 다 알아들으세요.

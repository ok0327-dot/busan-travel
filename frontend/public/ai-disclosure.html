AI 사용 정책 / AI Disclosure

본 사이트는 데이터 정리·분류·요약에 AI 모델을 보조 도구로 사용합니다. 각 단계가 어떤 AI 를 사용하고 어디서 인간 검증이 들어가는지 투명하게 공개합니다.

This site uses AI models as auxiliary tools for data classification, summarization, and place-name extraction. Each stage is documented below with human-verification checkpoints.

인간 검증 / Human verification

  • 분류 정정 표(CATEGORY_OVERRIDES) — 운영자 수동 관리, 외부 검증 데이터(Naver Local) 매칭
  • 185 건의 블로그 글 라벨 — Claude 가 직접 읽고 수동 추출 후 정적 표로 캐시
  • 매 cron 마다 회귀 테스트(verify_info_flow.py) — 깨짐 즉시 GitHub Issue 자동 생성
  • cron 실패 시 운영자 알림 — silent skip 차단 정책

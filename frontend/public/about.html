주말부산 소개 / About

주말부산(busan-travel)은 부산 거주자·정기 방문자의 주말·가족 단위 활동 의사결정을 돕는 관광 큐레이션 도구입니다. Kakao Maps 기반 지도 + 660+ POI(맛집·카페·관광지) + 축제·공연·전시 + 공식 블로그 매거진 + 단기 예보를 한 화면에 모아 제공합니다.

busan-travel curates Busan tourism data — restaurants, cafés, attractions, festivals, official blog magazines, weather — for residents and frequent visitors making weekend/family decisions. Map-first UI with daily auto-refresh.

운영 주체 / Operator

개인 프로젝트입니다. GitHub: ok0327-dot/busan-travel (오픈소스, 코드/데이터 구조 공개).

Personal project. Open source on GitHub.

데이터 갱신 정책 / Update policy

  • 매일 06:23 KST — 전체 수집 (POI / 축제 / 블로그 RSS / 매거진 / 단기 예보)
  • 3시간마다 — 단기 예보만 재갱신
  • 모든 데이터는 R2 백업 + 30일 daily archive 보관 (재해 복구)

Daily full collection at 06:23 KST. Weather refresh every 3 hours. R2 backup with 30-day archive retention.

API / Public API
